## 6. SPA Fallback — IMPLEMENTED

**nginx.conf** `location /` block:
```nginx
root /var/www/careerpilot/frontend-dist;
index index.html;

location / {
    try_files $uri $uri/ /index.html;
    location ~* \.(js|css|svg|ico|woff2?)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }
}
```

**Covered deep-link routes (BrowserRouter):**
- `/demo`
- `/demo/jobs`
- `/demo/jobs/:stableId`
- `/demo/jobs/:stableId/fit`
- `/demo/ranked`
- `/demo/applications`
- `/demo/pipeline`
- `/demo/retention`

**API protection:** `/api/` and `/api/public/` locations are matched **before** the static block, so API requests are **never** rewritten to `index.html`.

## 7. Reverse Proxy (nginx) — IMPLEMENTED

**File:** `deploy/nginx.conf` — generic, no embedded certs, no hard-coded domain.

**Topology:**
```
https://<public-origin>
       │  nginx (this file)
       ├── /     → frontend/dist  (SPA fallback)
       └── /api/ → http://127.0.0.1:8000  (single-worker uvicorn)
```

**Key blocks:**

- `limit_req_zone $binary_remote_addr zone=careerpilot_public:10m rate=120r/m;` — ~160k IP capacity
- Commented HTTPS block (operator provides certs) + HTTP→HTTPS redirect template

## 8. Uvicorn Single-Worker Launcher — IMPLEMENTED

**File:** `deploy/start_api.cmd` (Windows batch)

```cmd
cd /d "%~dp0..\backend"
if not exist ".env" ( error & exit /b 1 )
py -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

**Linux/systemd equivalent documented in `deploy/README.md`:**
```ini
ExecStart=/opt/careerpilot/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

**Rationale:** The in-process rate limiter (`backend/app/rate_limit.py`) is per-process. Multiple workers = N× anonymous budget + divergent auth limits. `--workers 1` is mandatory.

**Loopback bind:** `127.0.0.1:8000` only. Port 8000 never exposed publicly — nginx is the only public entry.

## 9. Public API Rate Limiting — IMPLEMENTED

**Decision:** Anonymous `/api/public/*` **must** be rate-limited at the application layer (in-process, bounded, safe 429 with `Retry-After`, scope-isolated from auth limits). Proxy-level `limit_req` added as defense-in-depth.

**Implementation:**

1. **Config** (`backend/app/config.py`, lines ~76-78):
   ```python
   public_read_limit_per_ip: int = Field(default=120, validation_alias="PUBLIC_READ_LIMIT_PER_IP")
   public_read_window_seconds: int = Field(default=60, validation_alias="PUBLIC_READ_WINDOW_SECONDS")
   ```

2. **Limiter policy** (`backend/app/rate_limit.py`, `_initial_policies()`):
   ```python
   "public.read": RateLimitPolicy(
       max_requests=settings.public_read_limit_per_ip,
       window_seconds=settings.public_read_window_seconds,
       scope="public.read",
       key_prefix="pub",
   ),
   ```

3. **Router dependency** (`backend/app/routers/public.py`):
   ```python
   async def enforce_public_read_rate_limit(request: Request):
       client_ip = get_client_ip(request)
       await check_rate_limit("public.read", client_ip)
   router = APIRouter(dependencies=[Depends(enforce_public_read_rate_limit)], ...)
   ```

4. **Environment docs** (`backend/.env.example`): `PUBLIC_READ_LIMIT_PER_IP=120`, `PUBLIC_READ_WINDOW_SECONDS=60`

**Scope isolation:** `public.read` uses key prefix `pub:` — completely separate from `auth.login`, `auth.register`, `search.start`, `docgen.generate`.
