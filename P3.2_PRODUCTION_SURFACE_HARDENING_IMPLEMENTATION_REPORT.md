## 3. Security Rationale

- **Docs exposure:** FastAPI registers the OpenAPI schema and interactive docs as unauthenticated routes by default; in production they enumerate every private endpoint, its parameters, and its shape. Mounting them only outside production removes that disclosure at the routing layer (structural, not a wrapper), so no unauthenticated browser can ever reach the schema.
- **Headers:** each header is production-safe and browser-behavior-only (no response-semantics change for API clients): `X-Frame-Options: DENY` blocks framing a page in another site’s UI; `nosniff` prevents a proxy/attacker from reinterpreting a response’s MIME type; `strict-origin-when-cross-origin` is the modern conservative default for referrer disclosure. Applying them globally is both safe and standard — including on API JSON, which a browser may also display.
- **URL scheme:** scraped job URLs are untrusted third-party data. `new URL()` parsing + an explicit `http:`/`https:` allowlist means an executable scheme can never become a navigable `href`; malformed/scheme-less input is treated as unsafe and simply renders no link (graceful), rather than emitting a clickable raw string.

## 7. Known Limitations and Deferred Items (for P3.3/P3.4)

These were **deliberately not started** (P3.2 constraints).

- **Content-Security-Policy:** not implemented — a CSP that breaks the existing React/Vite app would be worse than none. A compatible CSP is a future (P3.x) item pending a frontend audit.
- **Related URL-rendering surface:** `Profile.tsx` renders user-authored portfolio/project URLs (`proj.url`) as links (lines 726, 1095). These are **self-entered candidate-profile values, not scraped** third-party data, so they are a materially lower risk than job URLs; they are out of the P3.2 “scraped job URL” scope. The same `safeExternalUrl` guard can be applied there later if desired.
- Explicitly excluded by constraints (not implemented): audit logging, SSRF remediation, JWT revocation / session hardening, broad security refactor, deployment changes, database migration, scraper changes.
